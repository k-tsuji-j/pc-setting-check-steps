STEP 1タスクビューを開き、検査に不要なウィンドウを閉じる

未完了

目標：次の状態になっていれば完了です

  • タスクビューに表示されている画面が、検査ページと画面共有の表示のみになっていること

操作手順

  1. キーボードの Windows キーと Tab キーを同時に押して、タスクビューを表示します
  2. 不要なウィンドウにマウスカーソルを合わせます
  3. ウィンドウの右上に表示される「✕」をクリックします
  4. 終了後、Esc キーを押して元の画面に戻ります

検査ページと画面共有の表示は閉じないでください。また、「共有を停止」は押さないでください。このページを別のウィンドウで開いている場合は、このページも閉じないでください。

STEP 2システムトレイを開き、アプリを終了する

未完了

目標：次の状態になっていれば完了です

  • 「︿」の中に、不要なアプリが残っていないこと
  • セキュリティソフト、日本語入力、音量、ネットワークは終了しないこと

操作手順

  1. 画面右下の「︿」をクリックして、隠れているアイコンを表示します
  2. 不要なアプリのアイコンを右クリックします
  3. 表示されたメニューから「終了」（または「閉じる」）を選択します
「︿」の場所・開き方がわからない場合

方法Aマウスで「︿」をクリック

方法Bキーボードで Windows ＋ B → Enter

未完了

目標：次の状態になっていれば完了です

  • ブラウザーのタブが、検査ページの1つのみになっていること

操作手順

  1. 画面上部に並んでいるタブを確認します
  2. 検査ページ以外のタブを「✕」で閉じます
  3. 検査ページのタブのみになるまで繰り返します
